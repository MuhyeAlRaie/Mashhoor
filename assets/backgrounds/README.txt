Optional background images for the games.

Defaults are drawn procedurally (brand gradients + skyline) so no files
are required. To use a custom background for Chicken Dash, upload an
image from the Admin panel (Chicken Dash tab -> Runner background).
For a file-based default, place an image here (e.g. bg-runner.jpg,
portrait 1080x1920) and set dash.backgroundImage in shared/branding.js
to "assets/backgrounds/bg-runner.jpg".
